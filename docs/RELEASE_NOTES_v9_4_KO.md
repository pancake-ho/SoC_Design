# v9.4 변경점과 적용 방법

2026년 11월 24일 개정입니다. 학생 문의를 계기로 게이트 SAIF 전력 경로를 재검토했습니다.

1. 제공 오류 수정: 게이트 SAIF에 RTL 이름 자동 매핑을 적용하던 옵션을 제거합니다.
   배열의 다른 비트에 활동이 붙어 '주석됨'으로 보이던 오류를 실제 연결 net별 대조로 검출합니다.
2. 판정 수정: 모든 missing 핀을 일괄 실패로 보던 로직을 수정합니다. 실제 NC output만
   coverage에서 제외하며 해당 셀 전력은 유지합니다. 연결 핀·net·포트 누락은 계속 실패입니다.
3. 근거 추가: 코너별 비트 감사 JSON, 전체 activity 보고서, 핀 연결표를 저장합니다.
4. 모델 한계 명시: SAED32 SRAM의 음수 internal·누설 0을 자동 기록하고 원본 수치를 보존합니다.
   라이브러리를 임의로 보정하거나 실제 SRAM signoff 수치로 해석하지 않습니다.

RTL·고정 포트·ISA·메모리 계약·벡터·공통 SDC·배점은 유지합니다. hold는 각 조에서 해결합니다.
같은 v9.3 설계와 --saif activity.vcd가 있으면 재합성 없이 전력만 다시 실행합니다.
VCD가 없으면 게이트 --saif부터 재실행합니다. 학생 RTL 수정 시에는 재합성이 필요합니다.
패치 명령과 결과 해석은 POWER_SAIF_KO.md를 따릅니다.
