# EE470 프로젝트 변경사항 2026년 11월 26일

## v10.1 교강사 검토본

- 공식 RTL·게이트 테스트는 `project_top`의 공개 포트, MMIO 상태, 결과 주소와 CPU commit만 확인합니다. 기준형 SRAM의 내부 계층·고정 응답 타이밍 검사를 제거했습니다.
- NPU 입력과 출력의 논리 주소·형식을 유지합니다. SRAM 뱅크 배치, 내부 클록, 패킹·캐시·버퍼는 조별 설계입니다. SRAM과 추가 로직은 DUT에 포함합니다.
- 초기 리셋 뒤 TB가 공개 host로 Xq·Wq·bias부터 적재합니다. 측정용 reset 해제부터 유효 DONE까지 재며 TB의 준비 및 후속 읽기는 계측 구간 밖입니다.
- 연습 F12는 랜덤 생성, 공식 평가는 교수자 지정 F12 snapshot과 SHA256 대조를 적용합니다.

## v10

- 부록 D에서 NPU의 3사이클 제한을 해제했습니다. `START` 뒤 읽기·계산·결과 쓰기를 자체 제어합니다. 파이프라인, PE 수, FSM 및 내부 버퍼는 팀이 설계합니다.
- 합성 로그에 IMEM과 DMEM의 SRAM 인스턴스를 확인할 근거를 남깁니다. CPU의 Harris 13개 필수 명령과 두 메모리 동작을 F01에서 확인합니다.
- RP는 Reserved Port입니다. 기존 신호에 8비트 확장 입력·출력을 7개씩 추가해 최종 입력 8개·출력 8개로 구성했습니다.
- F12 시작점은 공통 데이터 적재 후 `rst_n` 상승입니다. CPU의 NPU 실행 요청부터 최종 저장 완료까지 포함하는 실제 실행시간을 기록합니다. 같은 구간의 평균 전력과 시간으로 에너지(J)를 계산합니다.
- 실행시간·에너지·면적을 2:1:1로 평가합니다. 각 지표의 표준정규 누적확률을 가중합하고 교수자가 지정한 점수 범위에 매핑합니다.
- 팀별 hold 보정에는 data-path delay cell 또는 hold buffer를 활용합니다. 보정 후 공통 SDC로 여섯 시나리오의 setup·hold를 모두 확인합니다.
- 조별 제출일은 15주차 2026년 12월 10일 목요일입니다. 개인별 피어리뷰는 자기 조를 제외하고 평가 대상 조마다 제출합니다.

기존 팀 작업을 별도 보존하고, 새 패키지의 `project_top` 포트와 공식 테스트벤치를 기준으로 팀 RTL을 이관합니다. 새 폴더에서 합성, 게이트 시뮬레이션, SAIF를 실행합니다. 구체적인 명령과 결과 키는 `TESTBENCH_V10_KO.md`를 참조합니다.
